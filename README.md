# 🏏 IPL Ticket Booking Website

## About the Project
The IPL Ticket Booking Website is a simple website created using HTML and CSS. It allows users to explore IPL matches and book tickets through a user-friendly interface.

## Features
- Home page with IPL introduction
- Navigation bar
- IPL match details
- Ticket booking form
- My Bookings section
- Booking guidelines
- Attractive and user-friendly design

## Technologies Used
- HTML
- CSS

## Project Highlights
- Simple and easy-to-use interface
- Organized sections for match information
- Easy ticket booking form
- Designed for IPL cricket fans

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Objective
The main objective of this project is to understand HTML elements, forms, tables, links and basic website development.
